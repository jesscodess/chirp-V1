# chirp

chirp is a web application that allows users to search for and listen to sounds of different bird species from around the world. It uses the [Xenocanto API](https://xeno-canto.org/explore/api) in order to do so.
It is motivated by its author's fascination with nature, deep belief in education and interest in using technology to create learning tools.

Currently, chirp is made using simple vanilla JavaScript. The author's goal is to keep updating and improving the project using different methods and frameworks/libraries. The intention is for it to serve as a showcase of the author's evolution and expanding knowledge.

chirp is live on Github pages on [this link](https://jesscodess.github.io/chirp-V1/).
